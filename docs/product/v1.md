# Murmur V1 product definition

## Platform and application shape

- Support Windows 11 on the current x86-64 machine.
- Use Tauri 2 with a React and TypeScript interface, Rust for Windows integration, SQLite for structured local data, and ordinary local files for audio.
- Use an English interface and preserve Vietnamese text correctly throughout the application.
- Launch with Windows by default after onboarding and remain available in the system tray.
- Use a small temporary overlay for Dictation Session recording and Processing Mode. Meeting recording uses tray state plus start and stop notifications, without a persistent overlay.
- Provide a full window for dictation history, meetings, transcript editing, vocabulary, search, backup, and settings.

## Dictation Sessions

### Activation and capture

- Support configurable hold-to-talk and toggle shortcuts. Default hold-to-talk to `Ctrl+Win`.
- Begin capture immediately and show recording feedback within 100 milliseconds.
- Pressing `Escape` while recording cancels the session and deletes its audio.
- Follow the current Windows default microphone unless the user deliberately selects a Murmur-specific override.
- Hold one temporary audio file until transcription succeeds or every STT path fails. Delete it after success. Keep failed diagnostic audio for at most 24 hours.
- If an audio device disappears, preserve available audio, mark the missing interval, and notify without silently switching devices.

### Context and correction

- Capture the active process, window title, selected text, and surrounding focused-field text by default.
- Allow context capture to be disabled globally or for named applications.
- Never capture password fields, password managers, private browser windows, Windows security dialogs, or applications on the denylist.
- Hold each Context Snapshot only through correction and vocabulary learning, then discard it.
- Apply the same Cleanup Level to every transcription route, hosted or local.
- Light (default): fix punctuation, capitalization, agreement, and obvious grammar; remove only non-lexical fillers; keep every other spoken word in order, including false starts and self-corrections; apply Personal Vocabulary.
- Medium: everything in Light, plus keep only the corrected version of a spoken self-correction, drop false starts, repeated words, and verbal fillers, and fix clearly misrecognized words when context or Personal Vocabulary makes the intended word obvious. Never change meaning, tone, or order of ideas. Aggressive rewriting requires an explicit action.
- Preserve spoken English, Vietnamese, and mixed-language phrases. Translation requires an explicit action.
- Use Groq GPT-OSS 20B as the initial correction model with low reasoning effort, hidden reasoning, and a length-derived completion limit so the answer arrives within the three-second correction timeout. If hosted correction fails, times out, or is truncated, insert the Raw Transcript immediately. Do not queue delayed correction or load a local correction model.

### Speech recognition

Stream dictation through Deepgram Flux while the user speaks. If its live handshake fails,
AssemblyAI remains the only live-stream fallback. For finalized audio and Meeting Sessions, try
configured providers in this order:

1. Deepgram, using Flux for dictation and Nova-3 for meetings
2. Groq Whisper Large V3 Turbo
3. AssemblyAI
4. Local `whisper.cpp` with `large-v3-turbo-q5_0`

Rotate after quota exhaustion, authentication failure, provider service errors, or two consecutive timeouts. Do not rotate because the app guesses that a transcript looks poor. Show `Hosted`, `Hosted fallback`, or `Local` in the temporary overlay and keep exact provider details in history.

### Formatting and insertion

- Recognize `new line`, `new paragraph`, `bullet`, `numbered item`, `open quote`, `close quote`, and `literal` as the initial formatting commands.
- The `literal` prefix prevents command interpretation for the following phrase.
- Paste through the target application's normal edit path and keep the Dictation Result on the clipboard after every completed dictation. This preserves ordinary `Ctrl+Z` behavior and makes the text immediately recoverable. If insertion fails, retain the result on the clipboard and notify. Keep direct accessibility replacement out of the default path because UI Automation can report success without changing the visible document.
- Allow ordinary `Ctrl+Z` in the target application to undo inserted text.
- Mark raw fallback entries as uncorrected and show a brief `Raw` indicator without blocking insertion.

### History and vocabulary

- Keep Raw Transcripts, Dictation Results, insertion status, Processing Mode, provider details, and timing for seven days by default.
- Delete expired Dictation Sessions silently. Do not support pinning dictations.
- Observe only the inserted text range until focus leaves or 30 seconds pass.
- Create an Attributed Correction when the user changes that range.
- Silently learn a Personal Vocabulary substitution after the same correction appears three times.
- Provide review, deletion, and reset controls for learned vocabulary.
- Never send Personal Vocabulary as STT prompt text. Use it only in the correction layer.

## Meeting Sessions

### Sources and recording

- Support imported recordings, online calls, and in-person meetings.
- Build imported-file processing first, online capture second, and in-person capture third. All three belong to V1.
- Start and stop recording manually.
- Detect likely Zoom, Teams, Google Meet, Slack Huddles, and Discord calls and offer a Meeting Prompt to start.
- Offer a stop prompt when the detected call ends, its application closes, or both audio sources remain inactive for 60 seconds.
- Dismissing a Meeting Prompt silences it for that meeting. Provide `Don't suggest for this app`.
- Record microphone and WASAPI system audio as separate channels. Continue with any remaining channel if a device fails.
- Support four-hour meetings. Flush audio to durable chunks so crash recovery loses no more than five seconds.
- Normalize captured WAVs to mono 16 kHz PCM and split long sessions below hosted upload limits while retaining timestamp offsets.
- Explain recording responsibility once during onboarding. Never begin or end recording automatically.

### Transcription and speakers

- Transcribe after recording rather than promising a live meeting transcript.
- Prefer Deepgram Nova-3, then AssemblyAI, for diarization. Groq and local Whisper may produce transcripts without dependable bilingual diarization.
- For online calls, label the microphone channel `You` and system audio `Others` when stronger speaker labels are unavailable.
- For in-person meetings, use generic speaker turns when available and allow manual labels. Never invent speaker identities.
- Keep the Raw Transcript immutable. User corrections form an Edited Transcript that preserves raw segment and audio timestamp links.

### Meeting Briefs

- Generate a fixed Meeting Brief automatically after transcription.
- Use Groq GPT-OSS 120B initially, processing long transcripts in timestamped chunks before final synthesis.
- Include an overview, detailed topics, decisions, action items, open questions, and notable cited moments.
- State only transcript-supported facts. Put uncertain interpretations under `Possible follow-ups`.
- Link every decision and action item to supporting transcript timestamps.
- If required online processing is unavailable, keep a Pending Enhancement and resume automatically when connectivity returns.

### Meeting library

- Search titles, transcripts, speaker labels, and briefs with SQLite full-text search.
- Export Markdown and copy text to the clipboard. Skip PDF, Word, semantic search, and custom templates.
- Keep Meeting Sessions, recordings, transcripts, and briefs for 30 days by default.
- Show an expiry tag in the interface without sending expiry notifications.
- Allow meetings to be pinned indefinitely.

## Local data and privacy

- Keep application data under the Windows user profile and rely on the Windows account plus BitLocker rather than application-level encryption.
- Store provider and private-update tokens in Windows Credential Manager.
- Send no telemetry, performance data, or crash reports automatically.
- Keep rotating local diagnostic logs with transcript and context content redacted. Provide an explicit diagnostic export.
- Export and restore a plain ZIP backup containing the database, settings, Personal Vocabulary, meeting files, and a manifest. Exclude credentials and show a privacy warning.
- Preserve user data during ordinary uninstall. Provide a separate destructive uninstall action that resolves and displays every target path before deletion.

## Setup and updates

- Ship a per-user Windows installer and a deterministic setup CLI with structured JSON output.
- Let an explicitly authorized AI agent drive setup, including provider-key configuration.
- Accept secret values through standard input, redact them from output, and write them directly to Windows Credential Manager. Never place secrets in command arguments, files, logs, or Git.
- Download the checksummed local Whisper model during setup with visible progress. Allow skipping it and show `No offline STT` until installed.
- Configure startup, microphone checks, insertion checks, provider validation, model validation, and private-update access through the setup CLI.
- Host signed updater artifacts in private GitHub Releases.
- Store a fine-grained `Contents: read` token for this repository in Windows Credential Manager and use it only from Rust.
- Check for updates daily, download them automatically, and install a ready update on the next ordinary restart.
- Never restart while recording or processing a Meeting Session.
- Use Tauri updater signatures. Defer paid Windows publisher signing for this personal build.

## Acceptance criteria

| Area | Required proof |
| --- | --- |
| Capture | Recording feedback appears within 100 ms on the target machine. |
| Hosted dictation | A ten-second utterance inserts within two seconds after release under the test network. |
| Local dictation | A ten-second utterance inserts raw text within five seconds after release on the target machine. |
| Recovery | Provider fallback and insertion failure never lose a successful recording or transcript. |
| Languages | The private evaluation set covers 20 English, 20 Vietnamese, and 10 mixed-language dictations. |
| Meetings | One imported, one online, and one in-person 30-minute sample complete transcription and briefing. |
| Durability | A four-hour Meeting Session records successfully, and forced termination loses no more than five seconds. |
| Evidence | Every generated decision and action item links to a supporting transcript timestamp. |
| Privacy | Sensitive-field exclusions, context disposal, log redaction, retention, backup exclusions, and credential storage are verified. |
| Setup | A clean Windows 11 user can complete deterministic setup and diagnostics without a development toolchain. |
| Updates | A Tauri-signed private update downloads, waits through active work, and installs on an ordinary restart. |

The private speech evaluation audio stays outside Git. Provider changes require running the same evaluation set and comparing transcription errors, latency, diarization, and citation quality.
